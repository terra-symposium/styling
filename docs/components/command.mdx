Command provides a keyboard-first command list and SearchDialog wraps it in a searchable dialog.

## Public exports

- `Command`
- `CommandDialog`
- `SearchDialog`
- `CommandInput`
- `CommandList`
- `CommandEmpty`
- `CommandGroup`
- `CommandSeparator`
- `CommandItem`
- `CommandShortcut`
- `SearchEmpty`

## Import

```tsx
import { Command, CommandDialog, SearchDialog, CommandInput, CommandList, CommandEmpty, CommandGroup, CommandSeparator, CommandItem, CommandShortcut, SearchEmpty } from '@terra-symposium/styling/ui';
```

## Usage notes

Use the component family for the interaction or content role described above. For compound components, place each exported part inside its owning root and preserve the accessible label, keyboard behavior, and state semantics. Check the exported TypeScript props for required values and controlled-state options.
