After [installing Styling](/styling/0-repository-guide/installation/), import components from the `ui` entry point and hue utilities from the package root.

## Import components and theme helpers

<CodeBlock
	language='tsx'
	code={
		"import { useEffect } from 'react';\nimport { applyHue } from '@terra-symposium/styling';\nimport { Button, Card, Input } from '@terra-symposium/styling/ui';\nimport '@terra-symposium/styling/global.css';\n\nexport function Example() {\n\tuseEffect(() => {\n\t\tapplyHue(220);\n\t}, []);\n\n\treturn (\n\t\t<Card variant='primary-tonal'>\n\t\t\t<Button variant='primary-glass'>Open workspace</Button>\n\t\t\t<Input aria-label='Workspace name' defaultValue='Terra Symposium' />\n\t\t</Card>\n\t);\n}"
	}
/>

The `ui` entry point exports shared primitives, form compositions, the data table, public variant contracts, and associated types. See the [component catalog](/styling/1-colouring/2-components/) for live examples and the [Hue guide](/styling/1-colouring/0-hue/) for scoped palettes.

## Optional Tailwind preset

Most applications can use the prebuilt `global.css` stylesheet directly. If the host compiles additional Styling classes with Tailwind, it can extend its configuration with the package preset:

<CodeBlock language='js' code={"import terraStyling from '@terra-symposium/styling/tailwind-preset';\n\nexport default {\n\tpresets: [terraStyling],\n};"} />
