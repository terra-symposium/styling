## Explore components

Compose from the shared component library and make only the changes needed for Terra's visual roles. Every interactive component should communicate hover, focus, disabled, loading, and error states clearly. Keep motion purposeful and respect reduced-motion preferences; the state change must remain legible without animation.

Search by component name, then open a reference for a live example, copyable source, usage guidance, and the TypeScript API. The [component pipeline](/styling/0-repository-guide/3-component-pipeline/) explains how those parts are maintained.
