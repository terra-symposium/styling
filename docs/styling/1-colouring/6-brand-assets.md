## Brand assets

Use the Website Media Kit's horizontal italic wordmark asset on the Website and in print. On slide layouts, use an editable `terra symposium` text mark in Avara Bold Italic so it shares the content inset. A supplied consumer logo can replace it; `logo: false` removes it.

Workshop photographs show real students and events. Use them when the subject calls for a human image, preserve the focal point, and keep text off busy regions. Give images useful alt text in UI and Docs. Avoid decorative stock images or placing a photo on every slide.

![Media Kit showing italic and regular Terra wordmarks, icon mark, and real workshop photography](/_docs/assets/styling/1-colouring/3-design-language/assets/website-media-kit.png 'Public Website · logo files and photography')

The PowerPoint uses an editable text brand mark on each layout. Install Avara Bold Italic for faithful native rendering.

![Presentation cover with an editable Terra text mark on a saturated field beside a pale panel](/_docs/assets/styling/2-documents/assets/presentation-cover.png 'PowerPoint · editable text mark')

[Open the Website Media Kit](https://terrasymposium.com/assets/) for the public reference. For source files, use the Website's `astro/src/assets/logos/` directory.
