# Brand assets

Use the Website Media Kit's horizontal italic wordmark asset on the Website and in print. On slide layouts, use an editable `terra symposium` text mark in Avara Bold Italic so it shares the content inset. A supplied consumer logo can replace it; `logo: false` removes it.

Workshop photographs show real students and events. Use them when the subject calls for a human image, preserve the focal point, and keep text off busy regions. Give images useful alt text in UI and Docs. Avoid decorative stock images or placing a photo on every slide.
