Terra Styling is the shared design package for Terra projects. It provides React components, a hue-based colour system, compiled stylesheets, and editable Word, PowerPoint, and spreadsheet templates. Applications use these building blocks to keep their interfaces and generated documents consistent while choosing their own palette.

## What the repository contains

- **`src/lib/`** holds the public hue utilities and Tailwind preset. The package root exports helpers such as `colors`, `applyHue`, and `getHue`.
- **`src/components/` and `src/ui/`** hold reusable React controls, composed form and table components, and the public `@terra-symposium/styling/ui` entry point.
- **`src/styles/` and `src/assets/fonts/`** provide the source styles and fonts. Import `@terra-symposium/styling/global.css` once in a host application; `effects.css` is available separately for visual effects.
- **`src/documents/`** provides the `@terra-symposium/styling/documents` API and editable Office templates.
- **`docs/styling/`** contains this guide and its live component examples. **`site/`** serves the documentation site; **`scripts/`** builds the package and reference material; **`tests/`** checks the library and components.

For a first integration, follow [Installation](/styling/0-repository-guide/0-installation/), then [Usage](/styling/0-repository-guide/1-usage/). Contributors can use the [Development guide](/styling/0-repository-guide/2-development/) for the repository layout and validation commands.
