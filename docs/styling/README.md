# styling documentation

This index helps readers find the Terra Styling guides and examples.

Start with the [repository overview](../../README.md). Configuration lives in `config/`, authored
implementation stays in its owning source tree, test plans and source are in `tests/`, and generated
output belongs in `dist/`.

For validation and pull-request guidance, see the [repository README](../../README.md).

## Documentation

- `agents/`: agents documentation.
- `node_modules/`: node_modules documentation.
- `styling/`: styling documentation.

The [test plan](../../tests/todo.md) inventories repository-owned functions and documents.
