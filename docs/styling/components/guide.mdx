# Component reference

The Styling package exports reusable controls, surfaces, menus, overlays, navigation patterns, and data helpers from `@terra-symposium/styling/ui`. The Components group in the sidebar contains an MDX guide for each component family exported by the UI package, including its related compound parts.

The component pages document each family’s exports and usage boundaries. Many include a rendered example using the package components. For exact prop types and controlled state, the generated TypeScript declarations remain the source of truth.

## Color and treatment variants

The shared palette contains primary, secondary, gray, destructive, success, and caution colors. Actions, surfaces, and form controls each support their own set of treatments.

Open the [color and treatment matrix](/styling/matrices/color-treatment/) to compare every button and card combination. The page explains how to read the matrix and renders its examples using the exported Button, ButtonLink, and Card components.

## Component families

- **Actions and forms:** buttons, button groups, checkboxes, comboboxes, forms, inputs, selects, sliders, switches, textareas, and toggles.
- **Content and feedback:** alerts, avatars, badges, bubbles, cards, empty states, hints, messages, progress, skeletons, spinners, and tables.
- **Menus and overlays:** alert dialogs, commands, context menus, dialogs, drawers, dropdown menus, popovers, sheets, notifications, and tooltips.
- **Navigation and layout:** accordions, calendars, carousels, collapsibles, pagination, scroll areas, separators, sidebars, and tabs.
- **Data and composition:** DataTable, Field, and data-driven form helpers.

Select a family in the Components group to see its exported compound parts, import path, examples, and usage notes.
