---
title: Color and treatment matrix
description: How the shared component variants combine color and treatment, shown with buttons and cards.
---

import "../assets/reference-content.css";

import { Button, ButtonLink, Card, CardContent } from '@terra-symposium/styling/ui';

export const colors = ['primary', 'secondary', 'gray', 'destructive', 'success', 'caution'];
export const buttonTreatments = ['default', 'outline', 'ghost', 'tonal', 'glass', 'link', 'underline'];
export const cardTreatments = ['default', 'outline', 'ghost', 'tonal', 'saturated', 'glass'];

The matrix is a visual index of the combinations a component family supports. Each row selects a palette color; each column selects a treatment. The cell label gives the canonical `variant` value to use in React.

The matrix is intentionally family-specific. Buttons include link treatments, while cards include saturated surfaces. A cell exists only when that component family supports the combination.

## Button actions

Button variants combine six colors with seven action treatments. The gallery uses the real exported `Button` and `ButtonLink` components, so the labels and visuals follow the package contracts.

<div className='variant-matrix-scroll' tabIndex={0} aria-label='Button color and treatment matrix. Scroll horizontally to see all treatments.'>
	<table className='variant-matrix'>
		<caption>Button color and treatment matrix</caption>
		<thead>
			<tr>
				<th scope='col'>Color</th>
				{buttonTreatments.map((treatment) => <th scope='col' key={treatment}>{treatment}</th>)}
			</tr>
		</thead>
		<tbody>
			{colors.map((color) => (
				<tr key={color}>
					<th scope='row'>{color}</th>
					{buttonTreatments.map((treatment) => {
						const variant = color + '-' + treatment;
						return (
							<td key={treatment}>
								<div className='variant-matrix-cell'>
									{treatment === 'link' || treatment === 'underline'
										? <ButtonLink className='matrix-action' href='#card-surfaces' variant={variant}>Sample</ButtonLink>
										: <Button className='matrix-action' size='sm' variant={variant}>Sample</Button>}
									<code>{variant}</code>
								</div>
							</td>
						);
					})}
				</tr>
			))}
		</tbody>
	</table>
</div>

For example, use `variant='primary-glass'` for a glass primary action or `variant='secondary-outline'` for an outlined secondary action. Button links use the same matrix while rendering an anchor.

## Card surfaces

Cards share the six-color palette and support default, outline, ghost, tonal, saturated, and glass. Their default treatment is `primary-tonal`; pass a variant when a specific surface is required.

<div id='card-surfaces' className='variant-matrix-scroll' tabIndex={0} aria-label='Card color and treatment matrix. Scroll horizontally to see all treatments.'>
	<table className='variant-matrix'>
		<caption>Card color and treatment matrix</caption>
		<thead>
			<tr>
				<th scope='col'>Color</th>
				{cardTreatments.map((treatment) => <th scope='col' key={treatment}>{treatment}</th>)}
			</tr>
		</thead>
		<tbody>
			{colors.map((color) => (
				<tr key={color}>
					<th scope='row'>{color}</th>
					{cardTreatments.map((treatment) => {
						const variant = color + '-' + treatment;
						return (
							<td key={treatment}>
								<div className='variant-matrix-cell'>
									<Card className='matrix-card' variant={variant}>
										<CardContent className='matrix-card-content'>Sample</CardContent>
									</Card>
									<code>{variant}</code>
								</div>
							</td>
						);
					})}
				</tr>
			))}
		</tbody>
	</table>
</div>
