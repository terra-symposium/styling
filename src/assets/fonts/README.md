# Typeface credits

This file credits the creators of typefaces shipped with Terra Styling.

For validation and pull-request guidance, see the [repository README](../../../README.md).

## Usage

**Avara Bold and Bold Italic** — designed by Raphaël Bastide, with contributions by Wei Huang, Lucas Le Bihan, Walid Bouchouchi, and Jérémy Landes; released by [Velvetyne Type Foundry](https://velvetyne.fr/fonts/avara/). Licensed under the SIL Open Font License 1.1. See [licenses/OFL-1.1.txt](licenses/OFL-1.1.txt).

**AUTHENTIC Sans 90, 130, and 150** — distributed by [AUTHENTIC](https://authentic.website/sans) under the WTFPL.

**Inter Variable Roman and Italic** — Copyright (c) 2016 The Inter Project Authors; licensed under the SIL Open Font License 1.1. The files match the Inter font files used by the original Docs host. See [licenses/Inter-OFL-1.1.txt](licenses/Inter-OFL-1.1.txt) and [the Inter project](https://github.com/rsms/inter).

The font files are distributed unchanged from the copies already used by the Terra Symposium website, except Inter is included locally because its original Sanity CSS dependency did not travel with Docs. Their licenses are separate from the Apache-2.0 license for this package.

The `.ttf` files accompany the PowerPoint templates. Install `AUTHENTICSans-90.ttf`, `AUTHENTICSans-130.ttf`, and `Avara-BoldItalic.ttf` before editing in Office. PowerPoint uses the native font family names recorded in the presentation, while LibreOffice may substitute them when rendering previews. AUTHENTIC Sans permits preview and print embedding but does not mark itself as editable-embedding, so the editable template ships these installable font files beside the deck instead of promising font portability inside the `.pptx`.
